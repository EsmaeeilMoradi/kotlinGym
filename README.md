# kotlinGym — Kotlin Tour for Android (video companion)

Code for the YouTube series **Kotlin for Android** by [@esmaeeilmoradi-code](https://www.youtube.com/@esmaeeilmoradi-code).

Official language topics follow the [Kotlin Tour](https://kotlinlang.org/docs/kotlin-tour-welcome.html) (Beginner + Intermediate) with an **Android mindset** (Home, sync, lists, AppBar, UiState).

## Structure

```
part1/   Hello · types · collections · control flow · loops
part2/   Functions · classes · null · extensions · scope
part3/   Receiver · interfaces · objects · sealed/data/enum · properties · APIs
*/answer/ChallengeAnswer.kt   — peek only after you try
```

Each `Ex*.kt` file has its own `fun main()` — open it in **IntelliJ IDEA** or **Android Studio** and Run that file.

## How to use with the video

1. Watch the chapter.
2. Open the matching `ExNN_….kt`.
3. Change one line, Run, observe the console.
4. End of each part: solve `Challenge.kt` **without** opening `answer/`.
